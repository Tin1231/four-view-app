# Four-View Angular App

A simple Angular app with four views:
1. **Home** – Overview of all views  
2. **Calculator** – +,−,×,÷ calculator  
3. **Editor** – Notepad-style rich-text editor (Bold/Italic)  
4. **Quiz** – Five English questions about Vietnam & Yasuo

## Run Locally

```bash
git clone https://github.com/<your-username>/four-view-app.git
cd four-view-app
npm install
ng serve --open
